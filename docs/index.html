Local-first · Traceable · Human review

从原片到发布，每一步都可追溯。

RemixFlow 把素材理解、事实核对、故事设计、配音、音画剪辑、包装、质检和发布拆成一条明确的 0–14 步制作链。每个问题都能回到它真正产生的步骤，而不是在最终视频上不断打补丁。

不是“自动剪完”，而是把错误放回正确的位置。

很多制作流程的问题，不是缺工具，而是事实、故事、配音、镜头、字幕和发布资产混成了一团。RemixFlow 用步骤边界和 QC 文档把它们重新拆开。

Truth source

每一步只有一个真源

文案错了回文案，镜头错了回画面时间线，裁切错了回剪辑。下游不能偷偷替上游修错。

Feedback routing

反馈不再散落在聊天里

用户反馈先进入本期总账，再落到对应步骤 QC；修改、复核和最终状态都有明确记录。

Public / Local

展示与生产共用一套界面

GitHub Pages 展示公开 Demo；本地模式直接读取真实工程、编辑文档、预览视频并同步桌面交付文件。
